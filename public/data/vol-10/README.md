1. Mở trang **Quản lý dữ liệu** trên ứng dụng web để nạp trực tiếp file PDF, Audio MP3/M4A/WAV, Transcript (.txt/.srt/.vtt) và Key cho từng Test (lưu vào IndexedDB trên trình duyệt).
2. Hoặc xuất file `data.json` từ trình quản lý dữ liệu kèm `exam.pdf` và `audio.mp3` đặt vào `public/data/vol-10/test-{1..4}/` rồi push lên GitHub.
